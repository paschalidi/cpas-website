# CV Writing Reference

The user is improving their CV. This section captures the format, drafts in progress, and open questions so the work can be continued in another session.

## CV Format Template

Pattern, distilled from the EverCars entry below:

```
ROLE @ COMPANY | DATES | LOCATION
Brief context line (team size, scope, what they led).
- **Strong action verb** + what they did + (tech in parens) + measurable impact (metric).
```

Style notes:
- Bold the opening verb phrase of each bullet.
- Tech stack inline in parens, not in a separate "Tech:" line.
- Metrics where possible (e.g., "5x user growth", "62% higher conversion", "38% faster", "22.4%").
- Bullets are achievement-oriented, not task lists.
- Keep ~6 bullets per role.
